# Quick Notes for GNOME Shell

A tiny, local Quick Notes utility for GNOME Shell.

## Features

- Quick Notes icon in the GNOME top panel
- Single-click to open the notes menu
- Double-click to create a new note
- Edit individual notes
- Delete individual notes
- 8-second undo after deletion
- Notes persist locally
- Floating, movable note editor
- Multiline text editing
- Vertical scrolling for long notes
- No cloud account
- No network connection
- Plain-text notes

## Requirements

- Ubuntu / GNOME Shell
- GNOME Shell 50
